# Petal House Events — Website

The official website for **Petal House Events**, a Singapore event planning business offering birthday programmes, social events, gifting and décor rentals.

## What's inside

```
index.html          The complete website (all pages in one file)
assets/images/      Photos, logo and product images used by the site
.nojekyll           Lets GitHub Pages serve the site as-is
```

The site is a single static page with hash-based navigation:

| Page | Address |
|---|---|
| Home | `#home` |
| Services | `#services` |
| Birthday Programmes | `#birthday` |
| Social Events | `#social` |
| Gifting | `#gifting` |
| Rentals | `#rentals` |
| About | `#about` |
| Contact | `#contact` |

No build step or server is needed — open `index.html` in a browser.

## Publish with GitHub Pages

1. In this repository, go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Pick branch **main** and folder **/ (root)**, then **Save**.
4. After a minute the site is live at `https://raheebmubarak.github.io/petelhouseevents-website/`.

To use your own domain (for example `petalhouseevents.sg`), add it under **Settings → Pages → Custom domain** and point your domain's DNS to GitHub Pages.
